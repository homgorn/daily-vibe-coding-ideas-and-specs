# ROADMAP

Стратегические фазы проекта. Операционные пункты — в TODO.md. Еженедельно сверять и двигать статусы.

## Фаза 0 — Бутстрап (текущая)
**Цель:** репа живёт, документы есть, движок запускается локально.
**Статус:** в работе.
**Выход из фазы:** `python src/cli.py run` отрабатывает без ошибок на тестовых данных + GitHub push работает + тесты зелёные.

## Фаза 1 — Обкатка пайплайна (14 дней)
**Цель:** движок стабильно выдаёт ≥30 фич/день, ≥5 идей/день, ≥3 спеки/неделю; индексы строятся; валидация не пропускает мусор.
**Правила:** каждый день — ручной ревью дайджеста (10 мин); фидбек (рейтинги 1–5) в БД; пустой день — тоже отчёт.
**Выход из фазы:** 14 дней без падений, KPI-таблица заполнена, первая неделя публикаций в GitHub Pages.

## Фаза 2 — Публикации, боты, контент-киты
**Цель:** Publish Ledger + WP + GH Pages + CF Pages + TG owner-бот + email-ингест + media-бандлы + первый курс.
**Каналы текста:** WP (EN), GitHub Pages, CF Pages (поддомен), Telegram (публичный канал), LinkedIn, Bluesky, VK. X/Reddit/Quora — ручные пакеты + напоминания.
**PWA + пуши:** сайт-дашборд становится PWA (manifest + Service Worker + offline-кэш); Web Push (VAPID) — подписки читателей, уведомление при выходе новой идеи/контента/публикации.
**Авторы:** бренд-редакция + персоны (решение в этой фазе).
**Монетизация-прототип:** оферты Launch Kits (Lite/Standard/Premium) — структура, без приёма денег.

## Фаза 3 — Видео
**Цель:** YouTube + TikTok (полу-авто), видео-бандл на каждую идею, форматы 9:16/16:9/1:1, TTS, субтитры, AI-disclosure по правилам YouTube.
**Позже:** IG/FB и прочие видео-площадки (набор тегов/хэштегов/SEO под каждую — в TODO).

## Фаза 4 — Реклама и полная автоматизация
**Цель:** Meta Ads (MCP-адаптер), креативы на идею, affiliate-мост, авто-постинг, полный автопайплайн «идея → запуск» с логами и отчётами.
**Управление через TG:** контрольные команды (/run-daily, /status, /approve) — control-plane как в OpenClaw/Hermes.

## Фаза 5 — Масштаб и перманент
**Цель:** IPFS/Arweave-зеркала, уникальные домены (Cloudflare API), API для B2B, marketplace спеков, community, Mentor-агент, ML-прогноз трендов (на накопленных данных).

## Языковая стратегия
- **EN** — публикации: GitHub, WP, X, Substack, YouTube, LinkedIn, Bluesky
- **RU** — ты (логи, отчёты) + каналы: Telegram, VK, Дзен
- **Позже:** ES, PT (видео с локализацией TTS/субтитров), затем другие

## Модель обновления
- **Weekly (пн):** обновление frameworks (spec-kit, BMAD-METHOD submodules) + диф + обновление constitution; обновление legal-чек-листа (правила платформ меняются); KPI-сводка в owner-бот
- **По событию:** новый ингест/новость → инкрементальный прогон (режим переключается конфигом)
