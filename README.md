# Daily Vibe Coding Ideas and Specs

**Daily research engine: 30+ fresh features, projects, startups and top GitHub repos every day — synthesized into workable ideas and hyper-detailed, agent-ready specs for building and launching products.**

> Every idea → full launch package: spec, prompts, marketing kit, investor kit, ads, visuals, video, course lesson. Published as Markdown, on GitHub Pages / Cloudflare Pages mirrors, and (later) WordPress and social channels.

## What this repo is

A self-running research + synthesis + publishing pipeline:

- **Fetch** — GitHub trending, Hacker News, Product Hunt, Reddit, npm, RSS of major AI blogs, top repos by category (30+ items/day minimum)
- **News** — news parsing and pre-analysis, news → ideas
- **Ingest** — your manual input (paste, files, screenshots, email digests) goes through the same pipeline
- **Synthesize** — clustering, dedup, idea synthesis with **Viability Score** (market / competition / time-to-MVP / risk)
- **Spec** — deep multi-agent specs built on **Spec Kit** (Spec-Driven Development) + **BMAD** role templates
- **Media** — visual bundles: cards, carousels, OG images, video clips (HyperFrames), per-platform posts with SEO/GEO metadata
- **Validate** — 5 validation agents (data, text, image, video, post) + SEO/GEO checks + link checker
- **Publish** — Publish Ledger (single source of truth), channels: GitHub Pages, Cloudflare Pages, later WordPress/Telegram/LinkedIn/Bluesky/VK/YouTube/TikTok…
- **Index** — multi-level Markdown indexes (global → day → category → cluster → tag → idea), LLM wiki, cross-linking
- **Dashboard** — local static dashboard: status, ideas pipeline, publishing queue, your ratings, manual idea entry
