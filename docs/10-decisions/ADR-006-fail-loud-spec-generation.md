# ADR-006: Fail-loud генерация спек вместо молчаливого шаблона

**Date**: 2026-09-27
**Status**: Accepted
**Deciders**: owner
**Consulted**: — (найдено при подключении живого LLM)
**Informed**: —

## Context

`generate_spec()` просит модель вернуть JSON-объект из 12 Markdown-секций. На практике
свободные модели возвращают JSON в ```json-блоке, с прозой вокруг или с обрезанными
полями. Код делал:

```python
try:
    spec_data = json.loads(response.content)
except json.JSONDecodeError:
    spec_data = _fallback_spec(idea)   # тихий откат на шаблон
```

`_fallback_spec()` подставляла заглушки: `## Solution — See summary above.`,
`1. Core feature (P0)`, `Python + SQLite + Markdown`, и — что хуже всего —
`## Cited Sources — Generated from fetched items.`

Последствия, найденные 2026-09-27 при генерации живой моделью:

1. **Все 12 спек в репозитории были шаблонами.** Ни одной настоящей.
2. **Валидация давала 12/12 PASS.** Заглушка внешне неотличима от настоящей спеки:
   есть frontmatter, все 12 заголовков, метаданные, viability score.
   Агент `data` видел «Cited Sources» и считал цитирование выполненным.
3. **Это прямое нару constitution §1** («данные — правда») и §3 («публикуется только то,
   что прошло валидацию»): валидация проходила артефакты без единой цитаты.

То есть проект публиковал пустоту, проходящую все гейты. Хуже, чем отсутствие вывода:
по спекам нельзя отличить «модель не ответила» от «есть готовый план сборки».

Дополнительно: `models.provider` в `config.yaml` отсутствовал, и реестр молча уходил
в `mock` — «зелёный» прогон вообще ничего не доказывал.

## Decision

1. **`extract_json_object(text)`** — единый парсер ответа модели:
   снимает ```json / ``` ограждения, затем ищет внешнюю пару `{...}` скобочным
   сканом с учётом строк и экранирований. Покрывает fenced JSON, голую прозу
   вокруг и частичный вывод.
2. **Провал парсинга = fail-loud.** Тело спеки заменяется на
   `FALLBACK_MARKER` (`<!-- spec-generation-failed -->`) и явное предупреждение.
   Больше **не** пишутся: `TBD`, выдуманные секции, «Developers and builders»,
   фиктивные `Cited Sources`. Пустой артефакт честнее выдуманного.
3. **Девятый агент валидации — `generation`.** `validate_artifact()` ищет
   `FALLBACK_MARKER` и проваливает артефакт. Ручные плейсхолдеры в артефактах,
   которые проходят остальные 8 агентов, больше невозможны.
4. **Никаких `TBD`:** отсутствующее поле рендерится как
   `## <Заголовок>\n\n(not provided by model)` — видно, чего нет.
5. **`models.provider` обязателен в `config.yaml`.** Тест
   `test_shipped_config_points_at_real_provider` не даёт выключить провайдер
   по недосмотру.
6. **Спека с фолбэком не проходит валидацию, а значит не публикуется** —
   конституция начинает работать автоматически, а не декларативно.

## Consequences

### Positive
- Спека либо настоящая, либо явно помечена как несгенерированная. Третьего нет.
- Валидация наконец ловит то, ради чего существует: пустые артефакты.
- `extract_json_object()` повышает устойчивость ко всем моделям, а не только к одной.
- Тесты фиксируют контракт: 7 тестов на парсер и фолбэк, 3 на гейт валидации.

### Negative
- Часть прогонов теперь заканчивается меньшим числом опубликованных спек — это
  правильно, но выглядит как регресс по метрике.
- На mock-провайдере пайплайн не может произвести ни одной валидной спеки.
  Интеграционный тест теперь это утверждает, а не обходит.
- Нужен ручной шаг перегенерации (`tools/reset_fallback_specs.py` +
  `tools/regen_specs.py`) для уже сгенерированных артефактов.

### Neutral
- `cited_sources` больше не может быть пустым: пустое поле видно как отсутствие.

## Alternatives Considered

| Alternative | Pros | Cons | Why rejected |
|-------------|------|------|--------------|
| Оставить silent fallback | Ноль изменений, всегда есть артефакт | Публикует выдумку, валидация слепа | Нарушает конституцию, неисправимо вниз по потоку |
| Улучшить только парсер | Чинит большинство случаев | При редком сбое снова молча врёт | Парсер не может гарантировать успех; нужен второй рубеж |
| Падать и не писать файл | Совсем чисто | Теряется след: непонятно, был ли запуск | Нужен видимый артефакт + причина, чтобы чинить |
| Ретраить до успеха | Больше настоящих спек | На free-пуле можно висеть часами | Уже решено бюджетами: `budget_minutes` + `fallbacks` |

## Compliance

- [x] Data is truth — фиктивные `Cited Sources` больше не генерируются вообще
- [x] Validation before publication — агент `generation` блокирует недозаполненное
- [x] Secrets only in .env — не затронуто
- [x] Markdown + index — не затронуто
