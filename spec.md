# Spec — что и зачем строим (Spec Kit: what/why, без техстека)

## Проблема

1. Мир вайб-кодинга меняется ежедневно: новые фичи, проекты, стартапы, топ-репозитории. Успевать невозможно.
2. Существующие дайджесты (TLDR, The Rundown, vibecodingtrends) — новости без продукта: они не отвечают на вопрос «что мне сегодня стоит построить и как?»
3. Запуск продукта даже по готовой идее — это 6+ дисциплин: спека, промпты, маркетинг, инвестор-материалы, реклама, видео. Ручной сбор — недели работы.

## Кто пользователи

- **Владелец (RU-юзер, без бэкграунда в разработке)** — получает автоматизированный пайплайн, отчёты, дашборд, напоминания; добавляет идеи руками и из рассылок.
- **Vibe-кодеры мира (EN)** — получают готовые идеи + спеки + Launch Kits для запуска своих проектов.
- **Покупатели офферов (позже)** — за деньги получают полный цикл запуска продукта по спеку под ключ.

## Пользовательские истории

- Как владелец, я хочу утром видеть статус пайплайна и «что сегодня интересного», чтобы быть в курсе без ручной работы.
- Как владелец, я хочу вставить текст/ссылку/скрин/рассылку из почты, чтобы агент проанализировал и предложил рабочие идеи со спеками.
- Как владелец, я хочу оценивать идеи (1–5) и видеть статус каждой, чтобы не теряться в потоке.
- Как vibe-кодер, я хочу видеть «Top 10 идей недели» и глубокую спеку с командами запуска, чтобы строить сразу.
- Как покупатель, я хочу получить полный бандл (спека + маркетинг + инвестор + адс + видео + курс) по идее.
- Как владелец, я хочу, чтобы всё публиковалось по правилам и с логами, чтобы не было юридических проблем.

## Функциональные требования

1. **Fetch (30+/день):** GitHub trending+API, HN, Product Hunt, Reddit (RSS), npm, RSS AI-блогов; дедуп по fingerprint; минимальный объём уникальных записей — конфигурируем (default 30).
2. **News:** парсинг новостей → анализ → идеи со спеками (2 прохода/день или событийно).
3. **Ingest:** ручной ввод (паста, файлы, скрины/OCR, email-рассылки через IMAP) → тот же конвейер; origin: user.
4. **Synthesize:** кластеризация, синтез идей, Viability Score (market/competition/time-to-MVP/risk, 0–100, confidence), тренды рынка.
5. **Spec:** глубокая спека на каждую идею (конституция + структура Spec Kit + роли BMAD) + launch-команды для IDE (Claude Code, OpenCode, Codex, Cursor, Antigravity) + копирование в буфер.
6. **Media:** визуальный бандл: карточки, карусели (Hook→Problem→Idea→Spec→Market Fit→CTA), OG, обложки, хэштеги под площадки; позже AI-арт фоны.
7. **Validate:** 5 агентов + SEO/GEO-чекер + link-checker + legal-check. Публикация без зелёного — невозможна.
8. **Publish:** Publish Ledger (реестр), каналы по уровням авто (A: API, B: одобрение, C: ручные пакеты), формат-матрица видео, зеркала.
9. **Index:** многоуровневые MD-индексы (в т.ч. свой INDEX.md на каждую идею) + SQLite + перелинковка по тегам/кластерам + LLM-вики.
10. **Dashboard:** лента дня, pipeline статусы, publishing-реестр, рейтинги, форма идеи, статус шедулов, KPI.
11. **Bots:** owner-бот (статусы, напоминания, ingest), публичный канал, позже control-plane.
12. **Courses:** авто-курсы из спеков (уроки из артефактов, геймификация-адаптер).
13. **Logs/Reports:** run-логи, chat-логи (резюме), publish-логи, weekly-отчёты (KPI), ADR.
14. **LLM-экономика:** кэш ответов, выбор модели по стадии, батч/инкремент.

## Успех

- ≥30 уникальных фич/день, ≥5 идей/день, ≥3 глубоких спеки/неделю
- 0 битых ссылок в публичных артефактах
- 100% публикаций с валидацией и записью в реестр
- 14 дней стабильных прогонов → публикация
- Владелец не тратит >10 мин/день на управление
