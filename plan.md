# Plan — технический план (Spec Kit: how)

## Стек

- **Язык:** Python 3.11+ (одна экосистема для всего движка), pytest для тестов
- **Хранилище:** SQLite (db/engine.db) + Markdown-зеркала; миграции через schema_migrations
- **LLM:** абстракция `providers/` (OpenRouter/OpenAI/Anthropic/локальные/OpenCode-дефолт); конфиг моделей по стадиям; кэш hash(промпт)→ответ
- **Фреймворки спеков:** vendored submodules `frameworks/spec-kit`, `frameworks/bmad-method` + weekly-updater
- **Сайты:** Astro (SSG) из publish/ → GitHub Pages (Actions) + Cloudflare Pages (push-интеграция); canonical-стратегия
- **Сайт-приложение:** PWA (manifest + Service Worker + offline-кэш) + Web Push (VAPID) — уведомления читателям о новых идеях/контенте/публикациях
- **Видео/картинки:** HyperFrames (HTML→MP4/PNG, headless Chrome) — детерминированно; TTS ElevenLabs; AI-арт — imagegen (по желанию)
- **Боты:** Python (aiogram или минимальный http long-polling) — отдельный процесс, модуль `bots/`
- **Публикации:** REST API адаптеры (WP, TG, VK, Bluesky, LinkedIn, YouTube, TikTok позже)

## Ключевые решения

1. **Событийность:** пайплайн = конвейер из шагов, каждый шаг идемпотентен; запуск по расписанию или по триггеру (ингест/новость); батч и инкремент — один код.
2. **MD = источник правды для человека, SQLite = источник правды для машин** (поиск, перелинковка, реестр); бинарный файл БД коммитится (бэкап), journal/wal — нет.
3. **Publish Ledger** — единый реестр всех публикаций (артефакт×канал×статус×URL×ошибка); ни один пост без записи.
4. **5 валидаторов + шлюзы:** каждый артефакт проходит валидацию на границе «создан→проиндексирован→опубликован».
5. **LLM-экономика:** free/дешёвая модель — fetch, аннотации, OCR; дорогая — синтез, спеки; кэш на пересборках.
6. **Безопасность:** .env вне git; тест на секреты; fine-grained GH token.
7. **Ручные шлюзы:** публикация в чужие каналы — после одобрения владельца (режим B), реестр напоминает.

## Риски и митигирование

| Риск | Митигирование |
|---|---|
| Mac спит / диск отмонтирован в час прогона | mount-чек + caffeinate-обёртка + пропуск с логом + время 11:00 |
| Лимиты API без токена | GITHUB_TOKEN обязателен, лимиты в конфиге, источники-расширители |
| Дубли между днями | fingerprint + таблица mentions |
| Стоимость LLM | кэш, модели по стадиям, бюджет-алерты |
| Падение прогона | ретраи, частичное сохранение, run-лог, dead-letter |
| Деградация качества синтеза | рейтинги владельца → фидбек в синтез |
| Правила площадок меняются | weekly legal-update, чек-лист в пайплайне |
